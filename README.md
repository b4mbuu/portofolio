# PHP болон Bootstrap ашигласан динамик портфолио

## Төслийн тухай

Энэ нь PHP болон Bootstrap дээр хийгдсэн динамик хувийн портфолио вэб сайт юм. Админ хэсгээр дамжуулан нүүр хуудасны мэдээлэл, үйлчилгээ, боловсрол, шилдэг ажлууд, статистик, сэтгэгдэл болон холбоо барих мэдээллийг удирдах боломжтой.

## Ашиглаж эхлэх

* Энэ төслийг татаж авах эсвэл clone хийх.
* `personal_portfolio` нэртэй өгөгдлийн сан үүсгэх.
* `personal_portfolio.sql` файлыг өгөгдлийн санд импортлох.
* Нүүр хуудсыг `http://localhost/personal_portfolio/` хаягаар нээх.
* Админ хэсгийг `http://localhost/personal_portfolio/admin/` хаягаар нээх.
